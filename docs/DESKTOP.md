# نسخة سطح المكتب (Windows)

## التنزيل
من صفحة [الإصدارات](https://github.com/bahattab/ai-legal-agent-arabic/releases/latest):

| الملف | متى تختاره |
|---|---|
| `Hakam-Setup-1.0.0.exe` | التثبيت العادي: اختصار في قائمة ابدأ وسطح المكتب، وإلغاء تثبيت من الإعدادات. لا يحتاج صلاحيات مسؤول |
| `Hakam-1.0.0-portable.exe` | تشغيل مباشر بلا تثبيت (من USB مثلاً). أبطأ قليلاً في الإقلاع |
| `SHA256SUMS.txt` | للتحقق من سلامة الملفات: `Get-FileHash .\Hakam-Setup-1.0.0.exe` |

**المتطلبات:** Windows 10 أو 11 (64-bit). النافذة تستخدم Microsoft Edge WebView2 المثبت مسبقاً في الأنظمة الحديثة؛ إن لم يوجد يفتح حَكَم المتصفح الافتراضي تلقائياً.

> الملفات غير موقعة رقمياً، لذا قد يعرض Windows SmartScreen تحذيراً: اضغط **More info** ثم **Run anyway** بعد التحقق من البصمة.

## أول تشغيل
1. افتح حَكَم، ثم **⚙ مزودو الذكاء الاصطناعي والنماذج** من الشريط الجانبي.
2. أضف مزودك وأدخل المفتاح، أو استخدم Ollama / LM Studio للعمل محلياً دون مفاتيح.
3. احفظ، ثم ارجع للمحكمة واطرح سؤالك.

## أين تُحفظ بياناتي؟
`%APPDATA%\Hakam` (الصق المسار في مستكشف الملفات):
- `legal_agent.db` — أرشيف القضايا
- `providers.json` — المزودون والمفاتيح (على جهازك فقط)
- `hakam.log` — سجل التشغيل لاستكشاف الأخطاء
- `.env` — اختياري، لنفس متغيرات نسخة الويب

إلغاء التثبيت لا يحذف هذا المجلد؛ احذفه يدوياً إن أردت مسح كل شيء.

## خيارات التشغيل
| الأمر | الوظيفة |
|---|---|
| `Hakam.exe` | نافذة التطبيق |
| `Hakam.exe --browser` | فتح الواجهة في المتصفح بدل النافذة (يوجد اختصار لها في قائمة ابدأ) |
| `Hakam.exe --smoke-test` | فحص إقلاع سريع يعيد رمز خروج 0 عند النجاح |

الخادم الداخلي يستمع على `127.0.0.1` فقط بمنفذ عشوائي، فلا يصل إليه أي جهاز آخر على الشبكة.

## البناء من المصدر
```powershell
# Python 3.12 + (اختياري) Inno Setup 6: winget install JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File desktop\build_windows.ps1
```
الناتج في `dist\`: مجلد `Hakam\`، الملف المحمول، والمثبّت.

البناء الرسمي يتم آلياً في GitHub Actions (`.github/workflows/release.yml`) عند دفع وسم `vX.Y.Z`: يبني الملفات، ويشغّل فحص الإقلاع على المجلد والملف المحمول، ويثبّت المثبّت بصمت ويفحص التطبيق المثبّت، ثم ينشر الإصدار.

## إصدار جديد
1. غيّر `__version__` في `version.py`.
2. أضف قسم `## [X.Y.Z]` في `CHANGELOG.md`.
3. `git tag vX.Y.Z && git push origin vX.Y.Z` — يفشل البناء إن لم يطابق الوسم `version.py`.
