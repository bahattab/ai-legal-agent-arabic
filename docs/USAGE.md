# دليل الاستخدام

يمكن استخدام "حَكَم" بثلاث طرق، اختر ما يناسبك:

| الطريقة | متى تختارها | ما تحتاجه |
|---|---|---|
| [1. تطبيق الويب](#1-تطبيق-الويب) | تريد واجهة عربية جاهزة وأرشيفاً للقضايا | Python + مفتاح OpenAI |
| [2. واجهة البرمجة (API)](#2-واجهة-البرمجة-api) | تريد دمج حَكَم في نظامك أو أتمتة الأسئلة | التطبيق يعمل محلياً |
| [3. مهارة AHLA](#3-مهارة-ahla-لأي-وكيل-ذكاء-اصطناعي) | تريد البروتوكول داخل Claude أو ChatGPT أو أي وكيل، دون تشغيل خادم | وكيل ذكاء اصطناعي فقط |

## 1. تطبيق الويب

```bash
pip install -r requirements.txt
cp .env.example .env          # ثم ضع OPENAI_API_KEY
python app.py
```
افتح `http://localhost:5000` ثم:

1. اكتب الوقائع والسؤال في مربع النص. **حدد الدولة** إن أمكن (مثلاً: "وفق نظام العمل السعودي").
2. اضغط **عرض على المحكمة** أو `Ctrl + Enter`. تستغرق المعالجة عادة بين 30 و90 ثانية (8 استدعاءات للنموذج).
3. يظهر الرأي النهائي، وتحته قسم **مراحل التفكير** القابل للطي:
   - **المرحلة A**: الوقائع، الأطراف، النوايا، النظام الحاكم.
   - **المرحلة B**: الفرضيات الثلاث، مع شارة "مقبولة/مرفوضة" ودرجة كل فرضية والثغرات التي أثارها الادعاء.
4. القضايا محفوظة في **أرشيف القضايا** بالشريط الجانبي. اضغط أي قضية لفتحها، أو **+ قضية جديدة** للبدء من جديد.

### نصائح لصياغة سؤال جيد
- اذكر **الوقائع** لا الانطباعات: التواريخ، نوع العقد (محدد/غير محدد المدة)، المبالغ، من بادر بالإنهاء.
- انقل **نص البند** المتنازع عليه حرفياً إن وُجد.
- اذكر **ما تريده عملياً**: معرفة المشروعية؟ تقدير التعويض؟ خطوات التقاضي؟
- سؤال واحد واضح أفضل من عدة أسئلة متداخلة؛ للأسئلة المتعددة افتح قضية لكل منها.

## 2. واجهة البرمجة (API)

### curl
```bash
curl -X POST http://localhost:5000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "هل يجوز لصاحب العمل خصم أيام الإجازة المرضية من الإجازة السنوية؟ (السعودية)"}'
```

### PowerShell (Windows)
```powershell
$body = @{ question = "ما مدة سماع الدعوى العمالية بعد انتهاء العقد في السعودية؟" } | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:5000/api/chat -Method Post `
  -ContentType "application/json; charset=utf-8" `
  -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

### Python
سكربت جاهز في [`examples/api_client.py`](../examples/api_client.py):
```bash
python examples/api_client.py "كيف أحمي فكرتي التجارية قبل عرضها على المستثمرين؟"
python examples/api_client.py --stages "سؤالك هنا"      # يطبع جدول الفرضيات ودرجاتها
python examples/api_client.py --batch examples/sample_questions.md   # يمرر كل الأسئلة في الملف
```

### متابعة قضية قائمة
مرّر `conversation_id` العائد من الرد الأول:
```json
{"question": "وماذا لو كان العقد محدد المدة؟", "conversation_id": 4}
```
> ملاحظة: الإصدار الحالي يحفظ الرسالة في القضية نفسها، لكنه لا يمرر الأسئلة السابقة للوكلاء؛ أعد ذكر الوقائع الأساسية في سؤال المتابعة.

### قراءة الرد
| الحقل | المحتوى |
|---|---|
| `response` | الرأي + التنبيه القانوني، جاهز للعرض |
| `final_response.opinion` | الرأي وحده |
| `stages.A.analysis` | التحليل الجنائي (Markdown) |
| `stages.B.hypotheses[]` | كل فرضية: `hypothesis_type`، `evaluation.score`، `evaluation.issues`، `passed` |
| `stages.B.passed_count` | عدد الفرضيات المقبولة من 3 |
| `stages.D.verified_hypotheses_count` | `0` يعني أن الرأي بُني على أعلى فرضية رغم عدم اجتيازها الحد — تعامل معه بحذر |

مثال كامل لشكل الرد في [`examples/sample_response.json`](../examples/sample_response.json).

## 3. مهارة AHLA لأي وكيل ذكاء اصطناعي

المجلد [`skills/0 - arabic-hakam-legal-analysis`](../skills/0%20-%20arabic-hakam-legal-analysis/SKILL.md) ينفّذ البروتوكول نفسه داخل الوكيل مباشرة.

### أوامر التشغيل
| الأمر | الناتج |
|---|---|
| `AHLA: <سؤالك>` | الرأي النهائي فقط مع سطر الافتراضات |
| `AHLA full: <سؤالك>` | المراحل A ثم جدول المداولة B ثم الحكم D |
| `AHLA json: <سؤالك>` | كائن JSON بنفس مخطط التطبيق |

### التثبيت حسب الوكيل
| الوكيل | الطريقة |
|---|---|
| **Claude Code** | `cp -r "skills/0 - arabic-hakam-legal-analysis" ~/.claude/skills/` |
| **Claude (الويب/التطبيق)** | ضغط المجلد في ملف ZIP ورفعه من قسم المهارات (Skills) في إعدادات Claude |
| **Codex / Gemini CLI / OpenCode / Cursor** | انسخ المجلد إلى مجلد المهارات الخاص بالوكيل (أو `.agents/skills` في المشروع) |
| **ChatGPT / Custom GPT / أي API** | الصق محتوى [`AGENTS.md`](../skills/0%20-%20arabic-hakam-legal-analysis/AGENTS.md) في التعليمات النظامية |

### الفرق بين المهارة والتطبيق
| | التطبيق | المهارة |
|---|---|---|
| استقلال الفرضيات | حقيقي (3 استدعاءات منفصلة) | داخل سياق واحد، إلا إذا دعم الوكيل وكلاء فرعيين |
| الادعاء المستقل | نموذج منفصل لم يكتب الفرضيات | الوكيل نفسه |
| الأرشيف | SQLite | سجل محادثات الوكيل |
| التحقق من النصوص | لا يوجد بحث | يستخدم بحث الويب إن توفر لدى الوكيل |

## أمثلة

> الأمثلة التالية توضح **شكل** الاستخدام والمخرجات. المقتطفات توضيحية مختصرة وليست آراء قانونية معتمدة.

### مثال 1 — بند تعاقدي (عمل)
**الإدخال:**
```
AHLA full: في عقد عملي غير محدد المدة بند يمنعني من أي عمل لدى الغير، حتى بدون أجر أو بتقديم مشورة،
وبند آخر يجعل تعويضي عن الفصل غير المشروع راتب شهر واحد، بينما تعويض الشركة ثلاثة أشهر. هل البندان صحيحان؟ (السعودية)
```
**شكل المخرج (مختصر):**

| المسار | الدرجة | القرار | أبرز ثغرة |
|---|---|---|---|
| الحرفي | 0.55 | مرفوضة | استنتاج "لا نص يحظره ← صحيح مطلقاً"، ورقم المادة غير متحقق من نصها المعدّل |
| المقاصدي | 0.80 | مقبولة | يحتاج ربطاً بنص نظامي محدد |
| الإجرائي | 0.65 | مرفوضة (مراجعة) | لم يحدد مدة سماع الدعوى |

> على الرغم من أن لصاحب العمل أن يشترط التفرغ ويمنع تعارض المصالح أثناء العقد، إلا أن الصياغة المطلقة التي تحظر حتى المشورة غير المنافسة تُوزن بميزان المصلحة المشروعة والتناسب… 1) احتفظ بنسخة العقد… 2) …

### مثال 2 — ملكية فكرية (دون تحديد دولة)
**الإدخال:**
```
AHLA: كيف أحمي فكرتي التجارية قبل عرضها على المستثمرين؟
```
**ما ستلاحظه في المخرج:**
- سطر افتراض صريح: "لم تُحدَّد الدولة؛ التحليل وفق المبادئ العامة المشتركة…".
- تمييز بين الفكرة المجردة (لا تُحمى عادة) وما يُحمى فعلاً: العلامة، حق المؤلف على العرض والكود، البراءة، السر التجاري.
- خطوات عملية مرقمة: توثيق السبق، اتفاقيات السرية حين تكون واقعية، الإفصاح المرحلي، عقود تنازل مع المساهمين.

### مثال 3 — مخرج آلي للدمج في نظام
**الإدخال:**
```
AHLA json: هل يحق للمؤجر رفع الإيجار أثناء مدة العقد دون موافقة المستأجر؟ (السعودية)
```
**المخرج:** كائن JSON واحد بالمفاتيح `A` و`B` و`D` (انظر [`examples/sample_response.json`](../examples/sample_response.json))، يمكن تمريره مباشرة لنفس واجهة عرض التطبيق.

### مثال 4 — حين لا تجتاز أي فرضية الحد
سؤال ناقص الوقائع مثل `AHLA: هل فصلي قانوني؟` ينتج غالباً درجات منخفضة لكل المسارات. يُبنى الرأي حينها على أعلى فرضية، مع **تصريح بعدم اليقين** وقائمة بالمعلومات المطلوبة (نوع العقد، سبب الفصل، الإشعار، مدة الخدمة). في التطبيق يظهر ذلك كـ `verified_hypotheses_count: 0`.

مزيد من الأسئلة الجاهزة للتجربة في [`examples/sample_questions.md`](../examples/sample_questions.md).

## استكشاف الأخطاء
| العرض | السبب المرجح | الحل |
|---|---|---|
| `OPENAI_API_KEY غير مضبوط` | ملف `.env` غير موجود أو فارغ | انسخ `.env.example` إلى `.env` وضع المفتاح |
| خطأ 500 يذكر `model` | النموذج غير متاح لحسابك | غيّر `HAKAM_MODEL_*` في `.env` إلى نموذج متاح |
| خطأ مهلة | النموذج بطيء | ارفع `HAKAM_API_TIMEOUT` |
| كل الفرضيات مرفوضة دائماً | الحد صارم للنموذج المستخدم أو الأسئلة ناقصة | أضف وقائع، أو اضبط `HAKAM_VERIFICATION_THRESHOLD` |
| نص عربي مشوّه في PowerShell | ترميز الطلب | استخدم مثال PowerShell أعلاه (UTF-8) |
