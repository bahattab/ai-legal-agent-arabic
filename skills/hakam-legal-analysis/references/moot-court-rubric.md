# معايير المحكمة الصورية (الادعاء العام)

ابدأ من 1.0 واخصم وفق الجدول، ثم قرّب لأقرب 0.05.

| الخلل | الخصم | مثال |
|---|---|---|
| مادة أو سابقة مختلقة/رقم غير متحقق يُقدَّم كيقين | 0.30 | "المادة 77 تنص حرفياً على…" دون تحقق من النص المعدّل |
| تطبيق نظام دولة أخرى أو خلط أنظمة | 0.25 | استدعاء قواعد مدنية مصرية في نزاع عمل سعودي |
| تجاهل واقعة جوهرية ذكرها السائل | 0.20 | إغفال أن العقد محدد المدة |
| قفز منطقي من المقدمة إلى النتيجة | 0.15 | "لا نص يحظره ← فهو صحيح مطلقاً" |
| إغفال قاعدة آمرة أو النظام العام | 0.15 | إقرار بند يُسقط حقاً لا يجوز التنازل عنه |
| نتيجة غير قابلة للتنفيذ عملياً | 0.10 | توصية بدعوى دون ذكر الجهة المختصة أو المدة |
| غموض أو عدم تحديد درجة اليقين | 0.05 | |

**القرار:** ≥ 0.70 Accept · 0.50–0.69 Revise (تُرفض في هذه الجولة) · < 0.50 Reject.

**نقاط قوة تُسجَّل:** استشهاد متحقق، تمييز دقيق بين الآمر والمكمّل، ربط الوقائع بالحكم، تحديد الأدلة المطلوبة.

**قاعدة الاستقلال:** يقيّم الادعاء كل فرضية بمعزل عن الأخريات ولا يعيد كتابتها.
